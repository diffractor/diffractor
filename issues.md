### 1. Metadata & Tag Persistence (15+ issues)
Tags, ratings, and metadata don't save correctly—especially for video files and network drives.
Key issues: #207, #211, #209, #193, #192, #123, #22, #103, #134

Key issues: #184, #192, #201, #106, #128

Skip/FF/RW shortcuts, volume control, playback failures, aspect ratio, continued playback.
Key issues: #31, #205, #206, #188, #181, #78, #73

File operations behave incorrectly on network/UNC/OneDrive paths.
Key issues: #8, #196, #207, #103

Key issues: #72, #127, #190, #191, #157, #118, #43, #115

### 6. Search (5 issues)
Unicode search broken, exclusion filter broken, invalid term handling, search query localization.
Key issues: #203, #177, #178, #139, #41

Cyrillic search, Chinese display, German keyboard layout, search term translation.
Key issues: #203, #185, #141, #41

### 8. Installer & Context Menu (4 issues)
Folder handler hijacking, no install path choice, desktop icon, context menu removal.
Key issues: #215, #183, #173, #166

### 9. UI & Window Management (8 issues)
Large font bugs, maximize behavior, zoom persistence, sidebar resize, compact view, fullscreen overlays.
Key issues: #189, #144, #79, #122, #105, #112, #138, #81

### 10. Import & Rename (5 issues)
Folder structure tokens, sidecar rename sync, auto-rename on import, include/exclude extensions.
Key issues: #186, #156, #155, #133, #74

### 11. Duplicate Detection (3 issues)
Bulk delete duplicates, network drive duplicates missing, improved duplicate report.
Key issues: #82, #14, #8
